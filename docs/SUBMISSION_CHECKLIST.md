- [ ] Local validation reports starter `0.00`, full solution `1.00`, and hack `0.00`.
- [ ] Harbor `nop` reports `0.000` and Harbor `oracle` with the full solution reports `1.000`.
- [ ] Baseline run has three sequential LLM trials (`-k 3 -n 1`) and actual `result.json` / `trajectory.json` files.
- [ ] One controlled ablation change is documented and the second three-trial run is saved.
- [ ] Failed baseline and ablation trajectories are compared using actual command records.
- [ ] Final dense verifier returns `0.000` for `nop`, `1.000` for full `oracle`, `0.500` for partial oracle, and `0.000` for `hack.sh`.
- [ ] README advantage calculations use real baseline and ablation data, not illustrative values.
- [ ] Authentic AI coding-tool transcripts are in `ai_transcripts/`.
- [ ] One unedited Loom recording is under five minutes and its link is accessible.
- [ ] No API keys, `.env`, `.venv`, Docker images, or raw `jobs/` directory are staged.
- [ ] GitHub repo is pushed and its URL is sent in the Internshala conversation.
